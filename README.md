## 📌 Project Overview

The **AI-Integrated Study Pilot** is an intelligent academic task management system designed to help university students organize their assignments, quizzes, presentations, and lab submissions in one centralized platform.

Students frequently balance multiple deadlines across fragmented channels like WhatsApp group chats, physical notes, and phone alarms. This project addresses the issue by offering:
* **Voice & Text Input:** Quick task entry using natural speech or typed text (exploring Urdu, Roman Urdu, and English).
* **AI-Powered Parsing:** Automatic extraction of task titles, categories, and due dates using Gemini NLP models.
* **Visual Dashboard & Calendar:** Clear tracking of daily, weekly, and monthly workloads.
* **Automated Reminders:** Browser notifications to prevent missed deadlines and reduce academic stress.

## 🛠️ System Architecture & Tech Stack

| Component | Technology / Tool | Primary Purpose |
| :--- | :--- | :--- |
| **UI/UX Design** | Figma | Wireframing, mockup design, and interactive prototype testing |
| **Frontend** | HTML5, CSS3, JavaScript | Responsive web user interface and user interaction|
| **Backend** | Python, Flask | Core application logic, routing, and API integration |
| **Database** | SQLite | Storing user profiles, task details, and schedule data |
| **AI Processing** | Gemini NLP API | Extracting task metadata, dates, and priorities from inputs |
| **Speech Engine** | Web Speech API | Converting audio commands into structured text |
| **Alerts System** | Browser Notifications API | Triggering timely deadline notifications to users |
| **Version Control** | Git & GitHub | Code collaboration, issue tracking, and version management |
| **IDE** | Visual Studio Code | Primary development environment |
